# 協力詰 問題コレクション (`rust/problems`)

本ディレクトリには、ogiekako（荻江香木・荻絵香木）の純粋な協力詰作品（全34局）およびベンチマーク用の協力詰作品を `.sfen` ファイルとして一元管理しています。

Web フロントエンドの作品集ページ（`/fmrs/ogiekako`）および Rust のテスト・ソルバーは、いずれも本ディレクトリの `.sfen` ファイルを直接パースしてメタデータと盤面を読み込みます。

## `.sfen` ファイルのフォーマット
