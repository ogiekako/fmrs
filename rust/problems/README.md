# 協力詰・ばか詰 問題集（ogiekako 作品集・収録問題一覧）

本ディレクトリには、ogiekako（発表名義：`荻江香木` / `荻絵香木` / `ogiekako`）による純粋な協力詰（ばか詰）作品37局と、ベンチマーク・比較用の他作者作品11局を収録しています。

## メタデータ仕様

1. **各 `.sfen` ファイル内のヘッダコメント（柿木将棋 KIF 標準情報行互換）**
   - `# 作品名`, `# 作者`, `# 発表誌`, `# 発表年月`, `# 手数`, `# ルール`, `# 受賞`, `# 出典URL`, `# 備考` を `# キー: 値` 形式で記述し、最終行に SFEN を記載しています。
   - `fmrs_core::sfen::decode_position` および CLI の `parse_to_sfen` は `#` で始まるコメント行と空行を自動的にスキップします。
2. **`metadata.json`**
   - 収録全問題の書誌情報・SFEN・fmrs 盤面URL・柿木将棋標準ヘッダ対応フィールド（`kif_headers`）を格納した JSON ファイルです。
